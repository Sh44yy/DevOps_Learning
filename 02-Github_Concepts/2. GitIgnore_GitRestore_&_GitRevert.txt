TOPIC: .gitignore, git restore, git revert

1. .gitignore
------------------------------------------------------------

.gitignore tells Git which untracked files or folders should
be ignored.

Example:

node_modules/
.env
passwords/
*.log

Common patterns:

file.txt       -> Ignore a specific file
folder/        -> Ignore a folder
*.log          -> Ignore all .log files

Check ignored/untracked files:

git status

IMPORTANT:
.gitignore does NOT stop tracking a file that is already
tracked or committed.


2. git restore
------------------------------------------------------------

git restore is used to undo uncommitted changes or unstage
changes.

Discard changes in one file:

git restore index.html

Discard changes in all files:

git restore .

Unstage a file:

git restore --staged app.js

IMPORTANT:
git restore can permanently remove uncommitted changes.


3. git revert
------------------------------------------------------------

git revert is used to undo the effect of an existing commit
while keeping the commit history.

View commit history:

git log --oneline

Example:

a82f91c Add login
4b72d11 Add navbar
91ac203 Initial commit

Revert a commit:

git revert a82f91c

Git creates a NEW commit that reverses the selected commit.

Example:

Commit 1 -> Working code
Commit 2 -> Wrong change
Commit 3 -> Revert Commit 2

The old commit is still present in the history.


4. QUICK COMPARISON
------------------------------------------------------------

.gitignore
-> Tell Git not to track specific untracked files/folders

git restore file
-> Undo uncommitted changes

git restore --staged file
-> Remove file from staging area

git revert <commit-hash>
-> Undo a committed change while keeping history

git reset
-> Move/change Git history depending on the option used


5. IMPORTANT GIT FACT
------------------------------------------------------------

A commit hash is an identifier for a Git commit.

It is NOT encryption.

Git uses the commit hash to identify a specific commit.


6. QUICK REVISION
------------------------------------------------------------

.gitignore -> Ignore files
restore    -> Undo uncommitted changes
revert     -> Undo commit + keep history
reset      -> Change/move history
