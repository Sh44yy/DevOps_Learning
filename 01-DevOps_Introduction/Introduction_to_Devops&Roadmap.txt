## 📚 What I Learned

### 1. What is DevOps?

**DevOps = Development + Operations**

DevOps is a culture and set of practices that brings software development and IT operations together.

The main idea is to:

* Develop software faster
* Automate repetitive tasks
* Test applications continuously
* Deploy applications reliably
* Monitor applications
* Get fast feedback
* Continuously improve the software

### 2. Development and Operations

The basic software process can be understood as:

```text
Plan
  ↓
Code
  ↓
Build
  ↓
Test
  ↓
Release
  ↓
Deploy
  ↓
Operate
  ↓
Monitor
  ↓
Feedback
  ↺
```

DevOps connects these stages and encourages continuous collaboration between development and operations teams.

## 👨‍💻 What Does a DevOps Engineer Do?

A DevOps Engineer helps developers and operations teams work together efficiently.

Some major responsibilities are:

* Building CI/CD pipelines
* Automating processes
* Managing servers and infrastructure
* Working with cloud platforms
* Managing containers
* Monitoring applications
* Improving reliability and scalability
* Managing infrastructure as code

## 📝 Day 1 Takeaways

* DevOps means Development + Operations.
* DevOps is a culture, practices, and way of working, not a single tool.
* Automation is a major part of DevOps.
* CI/CD helps automate software delivery.
* Git is used for version control.
* GitHub/GitLab provide platforms for Git repositories and collaboration.
* Linux is an important foundation for DevOps.
* Docker is used for containerization.
* Kubernetes manages containerized applications at scale.
* Ansible is mainly used for configuration management and automation.
* Terraform is used for Infrastructure as Code.
* Monitoring helps us understand application and infrastructure health.
* A good DevOps Engineer needs both technical and communication skills.
